# FUTURE_CS_01

## Vulnerability Assessment Report for OWASP Juice Shop

### Objective
Perform a passive security assessment of a web application and document findings.

### Target
https://demo.owasp-juice.shop/

### Tools Used
- Burp Suite Community Edition
- Browser Developer Tools

### Findings
1. Server Information Disclosure (Low)
2. Permissive CORS Configuration (Medium)
3. X-Frame-Options Implemented (Informational)
4. X-Content-Type-Options Implemented (Informational)

### Deliverables
- Vulnerability Assessment Report
- Evidence Screenshots
- Security Findings
